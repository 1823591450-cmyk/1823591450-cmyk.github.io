## 技术说明

纯静态站点，无框架、无构建步骤：

- `index.html` — 单页结构
- `styles.css` — 波普风格视觉：奶油纸底 `#FFF7E9`、半调网点、4–6px 黑描边、`10px 10px 0` 硬阴影、撞色块
- `app.js` — 视频播放器、路线切换、全屏模态、滚动进场动画
- `assets/` — 视频（H.264 / 1280×720 / AAC）、封面图、简历 PDF

无需安装依赖，直接用任意静态服务器打开即可：

```bash
python -m http.server 8000
```
